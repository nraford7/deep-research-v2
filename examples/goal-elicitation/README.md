# Example run: Dialogic goal elicitation and clarification

A complete deeper-research output, kept as a reference example of what the
pipeline produces. Topic: how skilled practitioners help people discover,
reframe, and decompose what they actually want (input to designing a
dialogic goal-clarification AI skill).

## Files

- `RESEARCH-BIBLE_dialogic-goal-elicitation.md` — the assembled reference
  document (~21,900 words, six sections plus bibliography).
- `bibliography.md` — deduplicated master bibliography (379 unique entries).
- `bibliography.bib` — the same, as BibTeX (377 entries).
- `claims.jsonl` — machine-readable extracted claims with source URLs.

## Provenance

Retrieval corpus of 394 sources across 27 slices; evidence gate passed;
draft passed a numeric background lint and an independent OpenAI-family
refute-mode adversary (41 HIGH findings), each resolved in a per-finding
fix pass. Raw fetched source texts are intentionally excluded (publisher
copyright); only original synthesis and citation metadata are included here.
